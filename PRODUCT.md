# UmiBridge

Local Windows gateway exposing authorized file, shell and desktop tools to ChatGPT through MCP, with a private dashboard.

## Corp

User-controlled chat orchestration within the existing UmiBridge dashboard. Users register chats, define an ordered sequence of work, explicitly start it and see real queue state through a Pixel Agents office. A locally paired Chrome/Edge extension interacts with already-open ChatGPT tabs. Provider quota notices pause tasks until their stored reset deadline. Unknown send outcomes require manual reconciliation.

Target devices: desktop and laptop only. No mobile delivery requirement. Preserve existing OAuth, tools, privilege controls and dashboard visual identity. Queues and chat content remain in excluded private state. No new AI service, account switching, quota bypass or autonomous task creation.
